## 📖 Описание проекта

**«Blog Customizer»** — это интерактивное React-приложение, позволяющее пользователю динамически настраивать внешний вид статьи блога в реальном времени. С помощью выдвижной боковой панели (сайдбара) пользователь может изменять шрифты, размер и цвет текста, цвет фона и ширину контента.

Основной акцент проекта сделан на верстке по Figma-макету, грамотном управлении состоянием в **React**, работе с хуками (`useState`, `useRef`, `useEffect`), динамическом управлении **CSS-переменными** и строгой типизации компонентной базы с помощью **TypeScript**.

### 📌 Цели и задачи проекта

- Разработка компонентной архитектуры интерактивного приложения по макету Figma.
- Реализация формы параметров стилей статьи с кастомными элементами управления (селекты, палитры цветов, переключатели).
- Управление состоянием внешнего вида через **CSS Custom Properties** (CSS-переменные).
- Настройка логики боковой панели: анимация открытия/закрытия, закрытие при клике на оверлей или клавишу `Escape`.
- Реализация сброса настроек к значениям по умолчанию и применения выбранной конфигурации.
- Деплой и публикация проекта на платформе **Netlify**.

### ✨ Функциональность

- **Выдвижная панель настроек (Sidebar):** открытие и закрытие боковой формы кастомизации.
- **Выбор гарнитуры шрифта:** переключение шрифтов статьи из предложенного списка.
- **Настройка размера шрифта:** выбор удобного размера текста.
- **Палитра цветов:** кастомизация цвета текста и фонового цвета статьи.
- **Ширина контентной области:** изменение максимальной ширины блока статьи.
- **Применение и сброс настроек:**
  - Кнопка «Применить» — динамически обновляет CSS-переменные контейнера статьи.
  - Кнопка «Сбросить» — возвращает все параметры к дефолтной теме.
- **Удобный UX:** закрытие панели при клике вне бокового меню (оверлей) или при нажатии на клавишу `Escape`.

### 🛠️ Стек технологий

- **React** (функциональные компоненты, хуки `useState`, `useRef`, `useEffect`)
- **TypeScript** (строгая типизация пропсов, состояний, событий и DOM-элементов)
- **CSS Modules & CSS Variables** (изолированные стили и динамическая смена тем)
- **Storybook** (изолированная разработка и тестирование UI-компонентов)
- **Webpack** (сборка проекта и настройка окружения)
- **Netlify** — хостинг и автоматический деплой приложения

## 💡 Выводы по результатам проекта

- **React & Управление состоянием:** Глубоко освоила работу с базовыми и пользовательскими хуками React (`useState` для хранения состояния формы, `useRef` для доступа к DOM-узлам и оверлею, `useEffect` для глобальных обработчиков событий).
- **Динамические CSS-переменные:** Научилась связывать состояние React-компонентов с CSS Custom Properties на уровне DOM-контейнера для мгновенного переключения внешнего вида статьи без перерисовки всего дерева.
- **Строгая типизация в TypeScript:** Закрепила типизацию React-компонентов, пропсов (`Props`), объектов конфигурации, а также событий форм (`FormEvent`, `MouseEvent`, `KeyboardEvent`).
- **Продвинутый UX & Обработка событий:** Реализовала паттерн закрытия модальных элементов при клике вне их области (Click Outside) и по кнопке `Escape` с корректным отмонтированием обработчиков.
- **Компонентный подход и деплой:** Построила масштабируемую систему переиспользуемых UI-компонентов и опубликовала готовый проект на **Netlify**.

## ⚙️ Инструкция по развертыванию и запуск

## Системные требования

- Установленный **Node.js** (версии 18.x или выше)
- Менеджер пакетов **npm**

## Инструкция по локальному запуску

1. Клонируйте репозиторий на свой ПК:

```bash
git clone git@github.com:afanassk/blog-customizer.git
```

2. Перейдите в директорию проекта:

```bash
cd blog-customizer
```

3. Установите зависимости и запустите проект в режиме разработки:

```bash
npm install
npm run start
```
